## 운영 상태와 검토 범위

운영 `/interview-management`는 HTTP 200, 비로그인 bootstrap은 HTTP 401을 확인했다. Supabase의 전용 5분 작업은 활성 상태이며 정기 실행 성공 이력이 있다. 추가 이메일은 발송하지 않았다.

소스는 `feature/interview-management-v2` 원격 브랜치 및 초안 PR로 전달한다. main 직접 수정·자동 병합·소스 정리를 위한 재배포는 하지 않는다. 기존 CLI 배포에는 main 밖에서 작업 중인 다른 기능이 포함돼 있을 수 있으므로, 병합 전에 PR 미리보기와 현재 운영 기능을 비교해야 한다. 운영 메일 허용 목록은 지정된 테스트 수신자 한 주소로 유지한다.
